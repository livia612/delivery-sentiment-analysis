 Delivery Sentiment Analysis AI
 Sobre o Projeto
Prova de Conceito (PoC) desenvolvida para demonstrar a implementação rápida de modelos de Machine Learning (NLP) focados em processamento de linguagem natural. O objetivo deste script é ler avaliações de clientes de delivery e classificar automaticamente o sentimento (positivo/negativo) usando um modelo pré-treinado.

 Tecnologias Utilizadas
Python 3

Hugging Face Transformers (Uso da pipeline de inferência)

PyTorch

Modelo utilizado: nlptown/bert-base-multilingual-uncased-sentiment

 Por que este projeto?
Como desenvolvedora com forte base em Engenharia de Software (Java, POO), meu objetivo com este projeto é demonstrar a capacidade de integrar e operacionalizar modelos avançados de IA (como LLMs e Transformers) para resolver problemas reais de negócio, como a triagem automática de feedbacks de clientes.
